Accessibility

The course should remain usable when the method of reading, navigating or interacting with it changes.

Last reviewed: 9 August 2026

Our approach

Static Carnival Technologies Limited is working towards conformance with the Web Content Accessibility Guidelines (WCAG) 2.2 at level AA. This is a statement of direction, not an unsupported claim that every page has passed a complete independent audit.

Features built into the course

  • Skip links and a consistent lesson sequence provide alternatives to repeated navigation.
  • Pages use semantic headings, landmarks, lists, tables and labelled controls.
  • The site is designed for keyboard navigation. A closed mobile lesson menu is removed from the focus order, and the menu button reports whether the menu is open or closed.
  • Lesson artwork has text alternatives and fixed dimensions to reduce disruptive layout movement.
  • The layout adapts to narrow screens and enlarged text.
  • Motion and transitions are reduced when the browser's reduced-motion preference is enabled.
  • The glossary search works without submitting personal information to a server.

Known limits

Programming examples can require horizontal movement when a line of code cannot sensibly be wrapped. Some of the original teaching terminology and linked third-party resources may be less accessible than the surrounding course. External websites are outside our control.

We are continuing to test the main page types with keyboard navigation, reflow and automated checks. If a test identifies a material barrier, we will record it here until it has been corrected.

Ask for help or report a problem

If you cannot use part of the course, email graham@staticcarnival.com. Please include the page address, what you were trying to do and, if you are comfortable doing so, the browser or assistive technology involved. We will consider a reasonable alternative and investigate the barrier.
