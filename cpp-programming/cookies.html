Cookie notice

The short version is unusually simple: this course does not use cookies, analytics or similar browser-storage technologies.

GitHub mirror hosting update: 11 September 2026

What the site stores on your device

The C++ Programming pages do not set cookies. They do not use local storage, session storage, IndexedDB, advertising identifiers, tracking pixels or browser fingerprinting. There are no analytics tags or social-media plug-ins. The Lesson 1 movie uses native browser controls and a media file delivered by GitHub, rather than a video-platform embed.

The lesson menu, reading-progress indicator and glossary search are ordinary page functions. They work locally in the browser and do not remember you after the page is closed.

Hosting and the movie

This mirror does not add tracking or advertising storage, and adds no consent banner. This is not a claim that GitHub's infrastructure or its own websites process no information. GitHub logs IP addresses for Pages security; playing or downloading the movie also contacts GitHub's delivery service. See the GitHub hosting notice and privacy notice.

If the site changes

We will review this notice before adding analytics, an embedded service or any feature that stores or reads information on a visitor's device. If a future feature requires consent, it will remain disabled until a visitor has made a clear choice, and refusing it will be as easy as accepting it.
