Hosting and privacy

This notice describes the GitHub copy of these courses.

Pages and movie delivery

This mirror uses GitHub Pages for the course pages and GitHub Releases for the Lesson 1 movie. It does not use Firebase Hosting to deliver this copy. Playing or downloading the movie requests a media file from GitHub; it is not a YouTube or other video-platform embed.

GitHub states that visitors' IP addresses are logged and stored for security when a GitHub Pages site is visited, whether or not the visitor is signed into GitHub. See GitHub's Pages documentation and the GitHub General Privacy Statement for its handling of service and usage information.

Course features

This copy adds no account system, contact form, analytics or advertising scripts. The lesson navigation, glossary and graphics experiments run in the browser. The movie uses the browser's native media controls. The course code does not add tracking cookies or browser storage.

GitHub's own websites, release-download service and infrastructure have their own data practices; this notice does not promise that those services collect no information. Following other external links is also subject to the destination's practices.

Course notices and contact

The C++ privacy notice and Graphics privacy notice provide course contact information. Hosting references in this mirror have been adapted for GitHub. No new reuse licence is granted by placing a public copy here; the existing course terms remain available.
