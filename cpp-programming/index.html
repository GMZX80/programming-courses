The purpose of this course

When I teach C++, I am not training students for a lifetime of typing program code into a computer. AI can now do a fair amount of that typing. This is useful, but typing was never the difficult part. The programmer must understand what the computation is actually doing. Where has the data gone? Why has the state changed? Is the answer correct, or merely convincing? Someone must decide what the program should do, inspect what it actually does and challenge it when it does something else. That someone is the programmer. If you think you are a programmer but do not accept this responsibility, then you are not an appropriate computer programmer. You are merely someone who can produce program code, and that is something quite different.
