# Programming courses

Public static mirror of the Static Carnival course pages by Professor Graham Morgan.

- [Course portal](https://GMZX80.github.io/programming-courses/)
- [C++ Programming](https://GMZX80.github.io/programming-courses/cpp-programming/)
- [Graphics Programming](https://GMZX80.github.io/programming-courses/graphics-programming/)
- [Corrected full Lesson 1 movie](https://GMZX80.github.io/programming-courses/cpp-programming/lesson-01-movie.html)

The movie lasts 52:20.480 and uses 46 slides, with four 30-second activity pauses and one 60-second pause. It has corrected, levelled sound. Its AI-generated presenter uses Professor Graham Morgan's authorised voice and likeness; it is not a camera recording of him delivering the lecture. Script-based English captions have approximate timing.

The existing `cpp-programming/lecture-01.html` is a separate 50-minute, 21-slide web lecture, with its own PowerPoint. It has not been replaced by the movie.

## Publication layout

`lessons-portal/public` supplies the repository root; `cpp-programming/public` and `graphics-programming/public` supply the corresponding subdirectories. Teaching prose, examples and existing slide images are preserved. Mirror-specific additions and navigation/hosting adaptations are recorded in `preservation-manifest.json`.

The movie is a GitHub Release asset, not a Git file:

[Download the complete Lesson 1 movie — MP4, about 893 MB](https://github.com/GMZX80/programming-courses/releases/download/lesson-01-v1/lesson-01-lecture-levelled.mp4)

The movie is published in [release lesson-01-v1](https://github.com/GMZX80/programming-courses/releases/tag/lesson-01-v1). GitHub's asset size and SHA-256 digest match the corrected master: 892,582,643 bytes; `cd77cd3305647f38f538a5e5236fe7e1ca8a573279ee0bd27d667dc5c4b81892`. If the browser cannot play it, use the direct MP4 link. The standalone caption file is `media/lesson-01.vtt`.

No private voice samples, portrait inputs, model weights, credentials, generation logs or local environment files belong in this repository. The previously public web-lecture PowerPoint has any source-machine path removed from its staged copy, without changing teaching notes or slides.

## Hosting and rights

This build is plain static HTML, CSS and JavaScript, with `.nojekyll` for GitHub Pages. Project-relative links support the `/programming-courses/` Pages path. The GitHub mirror has a [hosting and privacy notice](hosting.html).

No new course licence is asserted here. Existing course terms and any existing asset rights remain applicable; public availability is not a new permission to reuse the author's voice or likeness.
